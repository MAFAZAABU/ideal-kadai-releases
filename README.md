# Ideal Kadai for Windows

Billing, purchase and inventory for Indian shops.

**Download:** open [Releases](https://github.com/MAFAZAABU/ideal-kadai-releases/releases/latest) and run `IdealKadai-Setup-<version>.exe`.

This repository only holds the setup files. Installed copies of the app check here for new versions, and install one only when its SHA-256 matches the published `.sha256` file.
